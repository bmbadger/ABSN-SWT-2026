# ABSN Stepped-Wedge Trial Resources

This repository contains simulation code and summary metrics for the **BCWC-Trauma** study.

### REFERENCES

* **Hussey MA, Hughes JP.** Design and analysis of stepped wedge cluster randomized trials. *Contemp Clin Trials.* 2007;28(2):182-191.
* **Kasza J, et al.** Reporting of stepped wedge cluster randomised trials: a systematic review. *J Clin Epidemiol.* 2023;157:11-21.
* **Li F, Wang B, Heagerty PJ.** What is a stepped-wedge cluster randomized trial? *JAMA Intern Med.* 2025;185(5):593-594.
* **Nevins P, Ryan M, Davis-Plourde K, et al.** Adherence to key recommendations for design and analysis of stepped-wedge cluster randomized trials: A review of trials published 2016–2022. *Clinical Trials.* 2024;21(2):199-210.
* **Preisser JS, et al.** Developing Methods for Planning and Analyzing Stepped-Wedge Cluster-Randomized Trials. *PCORI Methodology Report (ME-1503-28119).* [https://www.pcori.org/research-results/2019/developing-methods-planning-and-analyzing-stepped-wedge-cluster-randomized-trials](https://www.pcori.org/research-results/2019/developing-methods-planning-and-analyzing-stepped-wedge-cluster-randomized-trials)
* **Ryan MM.** *StepWedgeSurvival: Tools for power analysis and simulation in SW-CRTs with time-to-event outcomes.* GitHub. 2023. [https://github.com/maryryan/survivalSWCRT](https://github.com/maryryan/survivalSWCRT)
